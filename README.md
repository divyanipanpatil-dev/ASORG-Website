# Simple ASORG Website

A simple, responsive company website developed as part of an internship task for ASORG SoftTech. The website presents the company's digital services, company information, contact details, and a newsletter section.

🌐 Project Overview

The ASORG website is a modern single-page company website designed to provide visitors with an overview of the company and its services.

The website includes:

- Responsive navigation bar
- Hero/banner section
- About Us section
- Services section
- Contact section with contact form
- Company footer
- Social media links
- Newsletter subscription UI
- Responsive design for mobile and desktop devices

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Custom styling and responsive design
- Bootstrap 5.3 – Layout and responsive components
- Bootstrap Icons – Icons used throughout the website
- JavaScript – Bootstrap functionality such as the mobile navigation menu

✨ Main Sections

1. Navigation Bar

The navigation bar provides links to:

- Home
- About
- Services
- Contact

It also includes a responsive Bootstrap navigation menu for smaller screens.

2. Hero Section

The hero section introduces ASORG SoftTech with a headline and short description.

It includes:

- Main heading
- Company introduction
- "Get Started" button
- "Learn More" button
- Hero illustration

3. About Section

This section provides a brief introduction to ASORG SoftTech and mentions the company's establishment in 2020.

It also contains an illustration and an "Explore More" button.

4. Services Section

The website displays three primary services:

- Web Systems – Custom websites and responsive web portals
- Mobile Apps – Mobile applications for iOS and Android
- UI/UX Mastery – User-focused interface and experience design

The service cards include hover animations for a more interactive experience.

5. Contact Section

The contact section provides:

- Company address
- Phone number
- Email address
- Contact form

The form contains fields for:

- Full Name
- Email
- Message

«Note: The contact form is currently a front-end UI only and does not submit data to a backend server.»

6. Footer

The footer contains:

- ASORG logo
- Company description
- Social media icons
- Quick navigation links
- Services links
- Newsletter subscription UI
- Copyright information

📱 Responsive Design

The website is designed to work across different screen sizes, including:

- Desktop
- Laptop
- Tablet
- Mobile

Bootstrap's responsive grid system and custom CSS media queries are used to improve the mobile experience.

🚀 How to Run the Project

No installation or build process is required.

Step 1: Clone the repository

git clone <your-repository-url>

Step 2: Open the project

Navigate to the project directory:

cd ASORG-Website

Step 3: Run the website

Open "index.html" directly in your web browser.

You can also use VS Code Live Server if available.
